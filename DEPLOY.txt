POCKET PROXY — RELAY DEPLOY FILES
=================================

Upload these FOUR files to the ROOT of your GitHub repo
(Add file -> Upload files -> drag them in -> Commit changes).
They must sit next to each other, not inside a subfolder.

  relay.js          the relay itself (~88 KB — never paste this one, always upload)
  node-server.cjs   the Node entry point (~13 KB)
  package.json      makes npm install / npm start work, with no dependencies (~0.4 KB)
  check.cjs         reports a truncated upload by name instead of crashing later (~4 KB)

RENDER SETTINGS — the defaults already work, nothing needs changing
  Build Command:  npm install            (or  node check.cjs )
  Start Command:  npm start              (or  node node-server.cjs )
  Node version:   anything 18+ (tested on 18.20.8, 20.20.2 and 26.10.0)

WHY THE DEFAULT COMMANDS WORK
  package.json has no dependencies and its start script is "node node-server.cjs", so:
    npm install    -> succeeds, nothing to install
    npm start      -> runs the relay
    npm run build  -> runs the file check

TWO ERRORS YOU HAVE ALREADY HIT, AND WHY THEY ARE NOW IMPOSSIBLE OR LOUD
  1. "SyntaxError: Unexpected end of input" at a line the real file does not end at
     -> the file was truncated in transit (copy-pasting from a preview window cuts
        off after a few KB). Upload files, never pasted text.
     -> check.cjs reports it by name and size, and the server itself refuses to
        start with a plain-language message if relay.js is short.
  2. "ENOENT ... Could not read package.json"
     -> the host ran its default npm build and found no package.json.
        package.json in this folder is the fix; keep it in the root.

CHECKING BY HAND ANY TIME
  node check.cjs                       # are the files complete? (no network needed)
  node verify.cjs                      # optional: boots a local relay and tests it (28 checks)
  node verify.cjs https://your-relay   # optional: tests a live deployment
