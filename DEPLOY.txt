POCKET PROXY — RELAY DEPLOY FILES
=================================

Upload every file in this folder to the ROOT of your GitHub repo
(Add file -> Upload files -> drag them all in -> Commit changes).
They must sit next to each other, not inside a subfolder.

  relay.js          the relay itself (~88 KB — never paste this one)
  node-server.cjs   the Node entry point (~13 KB)
  check.cjs         tiny file checker (~3 KB)
  client.html       the client — only needed if you host it from this repo
  verify.cjs        optional: the full 27-check end-to-end test
  DEPLOY.txt        this file

RENDER SETTINGS
  Build Command:  node check.cjs
  Start Command:  node node-server.cjs
  Node version:   anything 18+ (tested on 18.20.8, 20.20.2 and 26.10.0)

WHY THE BUILD COMMAND
  check.cjs reads each file as TEXT — it never runs it — so it can tell you a
  file was cut short while being copied or uploaded. Without it that shows up in
  the deploy log as "SyntaxError: Unexpected end of input" pointing at a line the
  real file does not end at, which tells you nothing. With it you get one line:

      SHORT    node-server.cjs  82 lines, 2.9 KB   <- truncated or incomplete

IF A FILE IS REPORTED SHORT
  It was truncated in transit. Pasting from a preview window can stop after a
  few KB, which is exactly how a file ends up ending mid-sentence around line 80.
  Re-send it as a FILE: download it (or unzip this bundle again), then drag it
  into GitHub. Do not paste it back in.

CHECKING BY HAND ANY TIME
  node check.cjs                          # are the files complete? (no network)
  node verify.cjs                         # boots a local relay and tests it end to end
  node verify.cjs https://your-relay      # tests a live deployment

WHICH FILES ARE ACTUALLY REQUIRED FOR RENDER
  relay.js and node-server.cjs. check.cjs is what you point the Build Command at.
  verify.cjs and client.html are optional extras.
